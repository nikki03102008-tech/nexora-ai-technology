# Nexora AI — Technology Website

A promotional website for a fictional AI technology company, presenting AI products, features, use cases, team members and contact information.

## Run locally
Open `index.html` in your browser.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — small interactive features

## Deploy with GitHub Pages
1. Create a new GitHub repository named `03_Nexora_AI_Technology`.
2. Upload the three website files and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose **main** and **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site. Copy the published website URL.

## Important
This is a frontend-only academic project. Replace sample personal/academic/contact information with accurate details before submitting. No backend or real student database is connected.
